# Movie Recommendation System (Spring Boot + Gradle)

A modernized movie recommendation web app built with **Java**, **Spring Boot**, and **Gradle**.

## Features
- Modern responsive UI (dark theme, card layout)
- Genre-based movie recommendations
- Fallback to top-rated picks when no genre matches

## Run locally
```bash
./gradlew bootRun
```
Then open `http://localhost:8080`.

## Test
```bash
./gradlew test
```
